# world/: the World Kernel
🌊 A Claude digest of canon (2026-11-21), built from `work/kernel/A–D`. The codex (`codex_v5/`) is the master; `decisions/BANK.md` and `decisions/RULINGS.md` override both. Nothing here is new canon.

**Reading order for agents**
1. `KERNEL.md`: the core (12 laws, hard rules, the aura). Every writer reads it before every chapter.
2. `GAP_QUEUE.md`: open world questions. Check it before a scene touches one; write around it, never answer it, and log hits there.
3. `ref/`: the full reference tier, one owner file per fact: `magic.md`, `cosmos.md`, `beings_world.md`, `characters_eras.md`. Read the file a scene needs.
4. If the kernel and the codex ever disagree, the codex wins (after BANK and RULINGS). Flag the drift; rebuild this folder after each ruling pass.
