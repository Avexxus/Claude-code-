# FLAGGED_ADDITIONS — the live tracker for unratified material (codex v5)

> **What this file is.** Everything that came up in the chats but is **not canon**: ideas Claude proposed that you never took up, questions Claude or you asked that were never answered, offers left hanging, and lines the verifiers found were Claude's wording rather than yours. None of it is written into the codex as canon. Some of it appears in the files as a 🌊 line; most does not appear at all.
>
> **Why it exists.** Method rule (`12_METHOD.md`, "Companion documents after every canon batch"): this tracker is refreshed with every canon batch so nothing proposed is lost and nothing unconfirmed slips in. The previous copy was lost with the old container; this is the rebuild from the v5 reports.
>
> **How to use it.** Each line gives the item, its source turn, and what it would need to become canon. Say "yes" (or give your wording) and it moves into its file on the next batch; say "no" and it moves to the 🚫 list at the bottom. Items that are a real *conflict between two sources* are not here — they are in `NEEDS_PATRICK.md` (cross-referenced as "NP #"). Items that are a story question still to be built (the master's identity, the hero's name, and so on) are in `11_OPEN_THREADS.md`.
>
> **Cite key.** `t###` = the October physics chat; `jul08 t###` / `jul23 t###` = the July chats. "Claude" = Claude proposed it; "Gemini" = an outside model's brainstorm; "Code" = Claude Code's archived files (not your words). Grouped by the file each item would land in; "also" names other files it touches.
>
> v5 — Oct 2026. Built from every `*_changes.md`, `*_round2.md` and `*_verify.md` report and the July recovery file.
